Bug fixes

edit
Aggregations
  • Keep the index sort’s missing value when rounding composite sources #165495 (issue: #165493)
Authorization
  • Fix built-in roles synchronizer spinning forever on duplicate sync completion #165643
  • Share in-flight application privilege loads #164884
CCR
  • Retry CCR if remote unavailable #165885
CCS
  • Preserve requested pagination in interim async cross-cluster search responses #163290 (issue: #160954)
ES|QL
  • Fail cancelled queries instead of returning partial results #163047 (issue: #162919)
  • Fix StringIndexOutOfBoundsException in EsqlCCSUtils #164790
  • Fix unfolded null errors on functions #162700 (issue: #162639)
  • Publish lazily computed plan fields safely #166189
  • Truncate invalid input in ES|QL TO_IP warnings #163347 (issue: #163299)
Geo
  • Fix handling degenerated polygons in vector tiles #164949 (issue: #164908)
Infra/Core
  • Fix race when reading reindex data stream status #164604 (issue: #164473)
Infra/Scripting
  • Turn off ASM compute limits in Painless #166227
Logs
  • Fix(logsdb): map host.name in pre-8.18 mixed clusters #165168 (issue: #164178)
  • [8.19] Fixed a bug where FLS did not always filter companion fields correctly #165476
Machine Learning
  • Drop permanently rejected results documents from the anomaly detection persister queue #164627 (issue: #164625)
  • Fix NPE in transform stats without a node #165935
  • Fix get filters/data frame analytics/transforms completing the listener multiple times on a corrupt document #164883
Mapping
  • Reject index sort fields without an IndexSorter #165267 (issue: #165265)
SLM
  • Fix threading in SLM create-snapshot failure handling #165528
Search
  • Fix hang on truncated compressed input #165840
  • Fix source filtering for fields containing backslashes #156238 (issue: #136302)
  • Return 400 for significant_terms on floating point values #165610
Searchable Snapshots
  • Forbid changing searchable snapshot identity on restore #164229
Snapshot/Restore
  • Handle exception from cloneShardSnapshot #164933
Transform
  • Fix GET _transform never completing when size is 0, and honour timeout and cancellation in its dangling task check #164829 (issue: #164850)
  • Treat SecurityExceptions like IndexNotFound #165350
