Bug fixes

Auditbeat

  • Fix auditd module failing or dropping events when immutable: true is set. #53707 #50189
  • Stop Auditbeat add_session_metadata stalling audit event reading after falling behind. #53853
  • Fix file_integrity kprobes backend failing on kernels that list .cold symbols first. #54106
  • Fix Auditbeat file_integrity realtime events on macOS when recursive is false. #54279 #54257

Filebeat

  • Fix awss3 input rejecting non_aws_bucket_name configs that set only default_region. #54143 #50021
  • Fix processors being applied twice to Elastic Agent filestream inputs configured without streams. #54416

Heartbeat

  • Stop leaking a thread per run when a browser monitor’s synthetics command fails to start. #52405

Libbeat

  • Encode the data_stream field set by the add_data_stream processor with lowercase keys in Beat receivers. #54224

Packetbeat

  • Fix length and count decoding in the Packetbeat Cassandra parser. #54067

Winlogbeat

  • Fix PowerShell module pipeline failure on unexpected or localized ParameterBinding lines. #54115
  • Fix PowerShell module pipeline failure on event 4103 with multi-line ContextInfo values. #54260
