Overview

edit

The collstats metricset collects collection-level operational and storage statistics from MongoDB. It transparently uses either the deprecated collStats database command (legacy) or the $collStats aggregation stage (MongoDB 6.2+) depending on server version and feature availability.

Notes: - For sharded clusters, stats from multiple shards are merged. The metricset reports an aggregate view and exposes a shardCount summary. It does not emit a per-shard breakdown (no shards.*). - Index size details (the indexSizes.* map) are intentionally not collected at this time.
