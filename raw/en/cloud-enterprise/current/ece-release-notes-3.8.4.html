Elastic Cloud Enterprise 3.8.4

edit

The following changes are included in this release.

Enhancements

edit

Fixed an invalid redirect.

During upgrades, made the stop docker container operation timeout respect the --timeout-factor parameter.

Improved reliability of ECE upgrades by adding configurable retry settings for Docker operations.

Added the --skip-steps flag to the ECE upgrader to bypass specific upgrade steps by name.

Added --disable-rollback to the ECE upgrader to prevent automatic rollback on failure or cancel.

Bug fixes

edit

Fixed node types to node roles migration during security cluster upgrades.
