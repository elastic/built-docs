Elastic Cloud Enterprise 3.8.7

edit

The following changes are included in this release.

Enhancements

edit

Upgraded the bundled Elastic Stack to 8.19.24.

Elasticsearch instances on versions 7.17.3 through 8.19.25 and 9.0.0 through 9.5.6 now start with the JVM Base64 intrinsics disabled, to mitigate a vulnerability in the bundled JDK that only affects hosts whose CPU supports AVX512_VBMI. The mitigation is on by default and takes effect the next time each instance restarts.

Updated third-party dependencies and base images to address security vulnerabilities.

Bug fixes

edit

Fixed ECE upgrade failure handling when steps are skipped. An upgrade run with --skip-steps could crash-loop or hang when a later step failed. The upgrade now finishes and reports a failed or rollback-skipped result.

During upgrades, the --timeout-factor parameter now also scales the delays used when waiting for containers and ZooKeeper. Previously, overloaded hosts could time out after about 60 seconds even with a larger factor.
