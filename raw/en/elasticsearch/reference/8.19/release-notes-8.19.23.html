Elasticsearch version 8.19.23

edit

Also see Breaking changes in 8.19.

Bug fixes

edit
ES|QL
  • Fixes a NullPointerException that occurred when ES|QL folded a regular expression that evaluated to null #158768 (issue: #158748)
  • Fixes the isPartial flag in ES|QL responses so that it is set correctly #157475 (issue: #157440)
  • Fixes ES|QL queries on indices where a nested field conflicts with an object field #158573 (issue: #154011)
  • Makes the ES|QL TO_BASE64, FROM_BASE64, MV_ZIP, and MV_CONCAT functions respect the circuit breaker, so large inputs return a circuit breaker error instead of exhausting memory #159659
  • Returns null values and a warning, rather than failing the query, when a typed GROK capture such as %{NUMBER:n:int} matches a value that can’t be converted to the requested type #160574
Extract&Transform
  • Limits the length of a connector description to 8192 characters #159638
Geo
  • Fixes the latitude correction in H3 cell bounds calculations so that it checks both edges adjacent to the extreme-latitude vertex #160228 (issue: #159682)
  • Limits the nesting depth of geometry collections when a geometry is created, preventing excessive recursion when a geo_shape runtime field emits deeply nested geometries #160004
Infra/Core
  • Ignores unrelated files when scanning the configuration directory for log4j2.properties #150016
Machine Learning
  • Adds the max_consecutive_extraction_failures datafeed setting. A real-time datafeed now stops automatically after repeated consecutive extraction failures instead of retrying indefinitely #159554 (issue: #158426)
Search
  • Improves consistency checks for point in time (PIT) IDs #160179
  • Fixes a memory leak where shard results that arrived after a search phase failed were never released #160439 (issue: #160321)
Security
  • Improves consistency checks for shard-level requests #159691
Templates
  • Reduces memory usage when retrieving component templates and composable index templates by streaming the response from the get component template and get index template APIs #158175

Enhancements

edit
Authorization
  • Grants the kibana_system role the manage, create_index, read, index, write, and delete privileges on the XM Cyber indices (logs-xm_cyber.device-*, logs-xm_cyber.product-*, and logs-xm_cyber.vulnerability_index-*). This lets the ILM delete step succeed for these indices #160185

Upgrades

edit
Infra/Core
  • Upgrades Jackson to 2.21.7 #160501
Network
  • Upgrades Netty to 4.1.138.Final #159561
