Fleet and Elastic Agent 8.19.17

edit

New features

edit
  • Add Azure Monitor receiver to EDOT Collector. #14443
  • Change bulk_response_filter_path in elasticsearch exporter configurations to match beats. #14452 #12688
  • Add Azure auth extension to EDOT Collector. #14665

Enhancements

edit
  • Disable TLS certificate hot-reload by default. #14599
  • Update OTel Collector components to v0.153.0. #14902

Bug fixes

edit
  • Preserve live install during upgrade cleanup and report aborted upgrades to Fleet. #14714
  • Apply policy log level changes after an agent restart. #14430 #13196
  • Notify endpoint-security just before symlink swap, not before upgrade attempt. #14481
  • Honour --path.logs when running elastic-agent run. #14476 #13320
  • Notify Fleet of agent uninstall before marking the installation directory for removal. #14581 #14142
  • Read TLS config from environment variables in container mode. #14758
  • Fix container config override inconsistencies. #14758
  • Fix a bug where an empty request body could be sent after failing over to an alternate Fleet host. #14844 #14773
