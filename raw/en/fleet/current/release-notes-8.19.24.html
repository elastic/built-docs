Fleet and Elastic Agent 8.19.24

edit

Security updates

edit
  • Bump npm to 12.2.1 and Node.js to 22.23.4 (24.22.1 on Wolfi) in the Elastic Agent complete Docker images to remove vulnerable undici copies. #17359

Enhancements

edit
  • Enable the Kafka exporter and receiver in FIPS builds. #16691
  • Update Go to 1.26.9. #17161
  • Update OTel Collector components to v0.163.0. #17249

Bug fixes

edit
  • Mark the elastic-agent-wolfi-complete image as complete. #16841
  • Fix an OTel Collector crash when all streams for a component are disabled. #16900
  • Fix a service runtime race that left Endpoint tamper-protected after an upgrade. #16917
  • Fix variables in Fleet policy inputs and outputs being resolved too early outside of the main Elastic Agent process. #16972
  • Rebuild the Fleet client when only the TLS or CA settings change in a policy. #17014 #17015
  • Fix Elastic Agent retaining component states that no broadcaster subscriber can receive. #17107
  • Fix the artifact downloader not using the Fleet Server URI for the PGP fallback. #17256 #16700
  • Retry the enrollment write on transient Elasticsearch errors to reduce offline agents that never enrolled. #7961 #7741
  • Avoid out-of-memory kills when many agents request artifacts right after Fleet Server starts. #8098
  • Refresh the PGP key when server.pgp.upstream_url is changed. #8122 #7836
