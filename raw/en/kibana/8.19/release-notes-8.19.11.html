Kibana 8.19.11

edit

The 8.19.11 release includes the following fixes.

Fixes

edit
Alerting
  • Fixes timestamp override for ES|QL CSV scheduled reports with relative time ranges (#248169).
Elastic Observability solution
  • Fixes incorrect dependencies stats (#249434).
  • Adds maxQueue backpressure to anonymization regex worker pool (#249108).
  • Uses monitor query ID for project monitors package policies (#248762).
  • Fixes an issue where synthetics test results showed up as duplicated on the monitor status heat map, for higher granularity columns (#248761).
  • Adds more granular control over how alerts behave when data stops being reported for metric threshold rules (#247669).
Elastic Security solution
For the Elastic Security 8.19.11 release information, refer to Elastic Security Solution Release Notes.
Kibana platform
  • Fixes an issue with the Share menu where all time ranges were being shared as absolute (#248804).
  • Fixes an issue with certain properties causing failures when adding a policy to an index template (#249168).
  • Fixes an issue with duplicated managed ILM policies still appearing as managed (#248586).
  • Fixes Stack Monitoring Recent Log Entries' timestamps to respect Kibana’s time zone setting (dateFormat:tz) (#249016).
