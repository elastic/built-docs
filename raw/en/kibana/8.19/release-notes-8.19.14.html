Kibana 8.19.14

edit

The 8.19.14 release includes the following known issues and fixes.

Known issues

edit
Stack and Observability alerts remain active instead of transitioning to recovered.

Details

Some Stack and Observability alerts send recovery notifications (for example, Slack, email, or webhook) but remain active in Kibana instead of transitioning to recovered.

Workaround
Manually untrack stale alerts or upgrade to 8.19.15, 9.3.4, or 9.4.0.

Resolved
This issue is resolved in 8.19.15, 9.3.4, and 9.4.0.

Fixes

edit
Dashboards and Visualizations
  • Fixes Lens panels appearing to revert after inline edits until you refresh the page, even though changes are saved (#256984).
Data ingestion and Fleet
  • Fixes Fleet bulk agent actions (unenroll, upgrade, reassign to policy) not respecting the current space when selection uses a kuery filter (#258582).
Data management
  • Restores keyboard focus to the Create a transform button on the Transforms page (#258095).
Elastic Observability solution
  • Fixes alert tags on inventory threshold, metric threshold, and custom threshold rules when tags are provided as a string instead of an array (#259729).
Elastic Security solution
For the Elastic Security 8.19.14 release information, refer to Elastic Security Solution Release Notes.
Elasticsearch solution
  • Fixes the query rules UI rejecting case variants as duplicate values (#259506).
  • Fixes only passing filtered rules to the API and deleting rules not matching the filter in the Query Rule Set editor (#259503).
Machine Learning
  • Fixes the anomaly swim lane dashboard panel not refreshing (#259962).
