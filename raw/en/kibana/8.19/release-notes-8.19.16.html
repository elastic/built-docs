Kibana 8.19.16

edit

The 8.19.16 release includes the following fixes.

The 8.19.16 release contains fixes for potential security vulnerabilities. Check our security advisory for more details.

Fixes

edit
Alerting
  • Fixes alert index template updates failing when auto-increasing total_fields.limit due to system-managed read-only fields (#262534).
Data ingestion and Fleet
  • Fixes integration package elasticsearch settings (index_mode, source_mode, dynamic_namespace, and dynamic_dataset) changing unexpectedly on package upgrade or reinstall (#269080).
  • Fixes Fleet background tasks failing when paginating agent policies sorted on the non-existent created_at field (#267285).
  • Fixes the IP Location processor in Ingest pipelines selecting the wrong database when a local .mmdb filename matches a managed database display name (#265740).
Elastic Security solution
For the Elastic Security 8.19.16 release information, refer to Elastic Security Solution Release Notes.
Elasticsearch solution
  • Fixes behavioral analytics APIs to reject collection names longer than 1024 characters (#266225).
