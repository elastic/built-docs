Kibana 8.19.17

edit

The 8.19.17 release includes the following known issues and fixes.

Known issues

edit
Canvas Autoplay stops advancing after one page.

Details
Multipage Canvas visualizations stop advancing after one page when in autoplay mode

Workaround
Manually advance to the next page or upgrade to 8.19.18 or 9.3.7.

Resolved
This issue is resolved in 8.19.18 and 9.3.7.

Fixes

edit
Alerting
  • Fixes the Alerts page fetching alerts twice on initial load, which briefly showed all alerts before the filtered set (#271441).
Dashboards and Visualizations
  • Fixes the autoplay timer in Canvas jumping to the wrong page when pages are added or removed (#268398).
Data ingestion and Fleet
  • Improves POST /api/fleet/setup performance for deployments with a large number of configured outputs by no longer decrypting every output on each call (#273848).
  • Fixes data stream selectors in input packages with multiple policy templates incorrectly sharing or duplicating variables between templates (#273364).
  • Improves response time of the agent policies list by computing counts in a single aggregation instead of multiple queries per policy (#272429).
  • Fixes missing security rule names in the Integrations → Assets tab (#272089).
Developer tools
  • Fixes autocomplete so GET is shown before DELETE when suggesting HTTP methods on an empty request line in Console (#270787).
  • Marks invalid HTTP methods (for example, GETT and POSTS) as errors in Console (#270479).
Discover
  • Fixes slow parsing when KQL queries contain long runs of whitespace (#266512).
Elastic Observability solution
  • Fixes overlapping messages in the Logs → Anomalies table by restoring single-line truncation with an ellipsis (#273221).
  • Fixes status tiles in the SLO Overview so that newly created SLOs are counted consistently with the per-row No Data badge (#266315).
Elastic Security solution
For the Elastic Security 8.19.17 release information, refer to Elastic Security Solution Release Notes.
