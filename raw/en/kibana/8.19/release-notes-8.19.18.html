Kibana 8.19.18

edit

The 8.19.18 release includes the following fixes.

Fixes

edit
Alerting and cases
  • Fixes case pushes only stamping a subset of attachments, which caused the alert count comment to be duplicated in the external system on every push (#274451).
Dashboards and Visualizations
  • Fixes Canvas autoplay not advancing past the first page (#272619).
Data ingestion and Fleet
  • Improves POST /api/fleet/setup performance for deployments with a large number of configured outputs by no longer decrypting every output on each call (#273848).
  • Fixes a crash in the Integrations view when a package has no icon (#273191).
Developer tools
  • Fixes Dev Tools Console autocomplete in query filter context to suggest query DSL instead of the obsolete Elasticsearch 1.x filter DSL (#272907).
Elastic Observability solution
  • Fixes deleting a label from a Synthetics monitor not persisting on edit (#274404).
Elastic Security solution
For the Elastic Security 8.19.18 release information, refer to Elastic Security release notes.
Kibana platform
  • Fixes the Files plugin blob download to return the requested file type (#274783).
  • Fixes an issue where the Kibana JSON logger could produce JSON objects with a large number of numbered keys (#256233).
