Kibana 8.19.20

edit

The 8.19.20 release includes the following fixes.

Fixes

edit
Data ingestion and Fleet
  • Fix Kafka outputs incorrectly accepting a proxy configuration, which Kafka doesn’t support (#282313).
  • Fix preconfigured Fleet proxies being rewritten on every Kibana startup even when unchanged, which needlessly incremented dependent agent policies (#281059).
  • Fix Fleet package policy bulk creation to store secrets in the secrets index instead of inline on the saved object, matching the existing create, update, and bulk update behavior (#282213).
  • Fix the create enrollment API key request to preserve an existing expiration value when creating the key in Elasticsearch security (#281324).
Data management
  • Fix ILM Explain in Index Management to include hidden and system indices when filtering by lifecycle phase (#282137).
  • Fix Cross-Cluster Replication to clear selected follower indices after a pause, resume, or unfollow action, so the Manage menu reflects the updated state (#273576).
Elastic Observability solution
  • Fix the Synthetics monitors overview failing to load maintenance window status for users with read-only access (#281894).
Elastic Security solution
For the Elastic Security 8.19.20 release information, refer to Elastic Security release notes.
Machine Learning
  • Fix the trained model infer, update, and stop APIs to prevent a deployment ID from being used to access a different trained model (#280511).
  • Fix the annotation and anomaly result search APIs to enforce job-level space access checks, and require a job ID on anomaly searches to prevent bypassing those checks (#277197).
  • Fix machine learning saved objects APIs to accept any one of the anomaly detection, data frame analytics, or trained models privileges instead of requiring all three, and correctly check trained models access when removing a saved object from a space (#276936).
