Kibana 8.19.24

edit

The 8.19.24 release includes the following enhancements and fixes.

Enhancements

edit
Elasticsearch solution
  • Clarify in the Salesforce connector’s document-level security tooltip that access applies per object type, not per record (#297728).

Fixes

edit
Alerting
  • Fix rules creating duplicate alerts, and leaving the original alerts active, when a rule run stops before it saves its state (#293521).
  • Fix rules and background tasks silently stopping for several minutes when a concurrent update prevents their completed run from being recorded (#295415).
Dashboards and Visualizations
  • Fix Lens metric panels failing to render when filters return no results and dynamic coloring uses a maximum dimension (#297429).
Data ingestion and Fleet
  • Fix deleting an agent policy silently leaving its ID in shared integration policies. The delete now fails with an error that explains the cause (#300189).
  • Fix Fleet running Elasticsearch transforms from uploaded integration packages with Kibana’s internal system identity. Transforms in uploaded packages now run as the user who installed the package (#297771).
Data management
  • Fix the runtime field editor discarding the script when you change the field type to or from composite (#299025).
  • Fix the runtime field preview not showing a field’s custom label, and the preview row disappearing while documents load (#299810).
  • Fix saved object labels showing "index patterns" instead of "data views" when you copy a dashboard that references data views in another space (#297621).
Discover
  • Fix field type icons staying stale in the field list when you recreate an index with a different mapping type for an existing field (#301198).
  • Fix the Url field formatter adding an extra /app segment to relative URLs that start with a slash when Kibana runs behind a base path or in a custom space (#299116).
Elastic Security solution
For the Elastic Security 8.19.24 release information, refer to Elastic Security release notes.
Elasticsearch solution
  • Fix content connector indexes created from Kibana failing to ingest documents with large numeric IDs by mapping the document id field as keyword (#297711).
  • Fix the Rule ID, Metadata field, and Values tooltips on the query rules Create rule page not being announced by screen readers in Chrome with VoiceOver (#295021).
Kibana platform
  • Fix tag filters in listing pages, such as the dashboards list, returning no results when a tag name contains an ampersand (&) (#297231).
  • Fix Permissions-Policy violation reports reaching the configured reporting endpoint only for the last directive. Reports for every directive now reach it (#299786).
  • Fix the Analytics overview page showing the Ingest your data section when you can’t add data or upload files (#297717).
  • Fix paging through the API keys list showing the same API key on more than one page, or leaving a key out (#296117).
Machine Learning
  • Fix the data frame analytics audit messages API returning messages for jobs that don’t exist in the current Kibana space (#297821).
  • Fix the ES|QL field statistics table being left empty when you change the query or time range while statistics are still loading (#298642).
  • Fix streaming inference connector requests returning no content when elasticsearch.compression is enabled (#290381).
