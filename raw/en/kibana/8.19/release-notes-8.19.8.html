Kibana 8.19.8

edit

The 8.19.8 release includes the following enhancements and fixes.

Enhancements

edit
Observability
  • Adds new sub-feature privileges for Synthetics global parameters (#243821).

Fixes

edit
Alerting
  • Fixes pagination for the Alerts table, which was getting stuck on rule details pages (#242275).
  • Fetches tracked alerts without depending on the task state (#235253).
Dashboards and Visualizations
  • Fixes an error that occurs when you deselect the (blank) option from the filter controls menu (#242036).
Data ingestion and Fleet
  • Adds retry behavior for /api/fleet/agents when transient issues with {Elasticsearch} are encountered (#243105).
  • Fixes ignore_above mapping for flattened fields (#238890).
Discover
  • Fixes truncation for longer text in the Discover table (#241440).
Elastic Observability solution
  • Fixes AI assistant only appearing in the Log overview for documents with the message field (#243437).
  • Improves handling of missing error.id in APM errors (#243638).
  • Reverts showing transform errors across all SLO pages (#243013).
  • Fixes the Kubernetes pod query by changing the gap policy to include zeros (#239596).
Elastic Security solution
For the Elastic Security 8.19.8 release information, refer to Elastic Security Solution Release Notes.
Kibana platform
  • Fixes the production build favicon’s CSS specificity (#243351).
  • Fixes an issue on the Index management page where screen reader text was different from visible text (#243802).
  • Fixes an issue with keyboard focus getting trapped on pages using document preview (#243791).
Machine Learning
  • Preserves cell selection in Anomaly Explorer when you click out of the Alerts popover (#244183).
  • Ensures deleted text in AI connector or Inference endpoint forms is not sent as empty strings (#244059).
  • Fixes import and improves validation for Anomaly Detection and Data Frame Analytics jobs (#242263).
