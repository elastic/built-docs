Kibana 8.19.13

edit

The 8.19.13 release includes the following fixes.

This release contains fixes for potential security vulnerabilities. Check our security advisory for more details.

Fixes

edit
Alerting and cases
  • Fixes an issue where webhook connector updates failed when the external service returned a 204 (no content) response (#251090).
Data ingestion and Fleet
  • Filters out unenrolled agents in the cleanup policy revisions task (#254899).
Discover
  • Fixes a rendering issue in the Attributes tab on the trace details flyout that caused the UI to become unresponsive (#255173).
Elastic Observability solution
  • Passes alerts data view to buildEsQuery for correct wildcard queries on keyword fields (#255225).
  • Fixes a crash in APM apps when invalid values were passed to rangeFrom and rangeTo URL query parameters (#256887).
  • Fixes an error on the SLO burn rate alert details page for suppressed alerts (#256435).
  • Fixes a 500 error and infinite loading on the APM Error group details page when the related transaction document is missing the transaction.sampled field (#255788).
Elastic Security solution
For the Elastic Security 8.19.13 release information, refer to Elastic Security Solution Release Notes.
Management
  • Fixes an issue in Dev Tools Console where syntax highlighting broke when queries contained accented or non-ASCII characters (#255649).
  • Fixes an issue in Dev Tools Console where closing nested braces broke syntax highlighting for subsequent elements (#255426).
Search
  • Fixes focus behavior when there are errors in the connector flyout form (#255770).
