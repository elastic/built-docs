Kibana 8.19.23

edit

The 8.19.23 release includes the following fixes.

Fixes

edit
Alerting
  • Fix forced rule runs and schedule changes being silently dropped when you request them while the rule is finishing a run (#293492).
  • Fix Jira Service Management and Opsgenie connector actions failing when the rendered alert message exceeds 130 characters. The connectors now truncate the message instead (#291698).
Data ingestion and Fleet
  • Fix the Fleet output edit flyout freezing or showing no counts when thousands of agent policies use the output (#291972).
  • Fix installed integration icons rendering as black shapes (#293176).
Elastic Observability solution
  • Fix the APM high-cardinality warning linking to outdated troubleshooting docs. The link now opens the APM common problems page (#290815) (#292214).
Elastic Security solution
For the Elastic Security 8.19.23 release information, refer to Elastic Security release notes.
Elasticsearch solution
  • Add an Expand site group members toggle to SharePoint Online connectors for compact document-level security (#288070).
  • Add a Sync all mail folders option to the Outlook connector (#291396).
Kibana platform
  • Fix Kibana shutting down when the product documentation installer downloads a corrupt or incomplete artifact (#291142).
Machine Learning
  • Fix the anomaly detection bucket span estimation API accepting an unlimited number of detectors, which could exhaust Kibana server resources (#291203).
  • Fix the field statistics flyout in the anomaly detection job wizard closing on its own while the wizard validates the job (#292297).
