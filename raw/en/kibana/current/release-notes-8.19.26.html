Kibana 8.19.26

edit

The 8.19.26 release includes the following enhancements and fixes.

Enhancements

edit
Elastic Observability solution
  • Show the Can run tests manually and Can manage rules sub-feature privileges as selected when you grant a role All privileges for Synthetics. Effective permissions don’t change (#302481).

Fixes

edit
Alerting
  • Fix bulk untracking of alerts also untracking alerts of rule types you aren’t authorized for, when the alerts belong to more than 10 rule types (#304048).
Data ingestion and Fleet
  • Fix the Fleet agent policy update API letting you change a policy’s ID. A request body id that differs from the policy you’re updating now returns a 400 error instead of being saved and returned as the policy ID (#303513).
  • Fix Fleet agent policy overrides accepting OpenTelemetry collector settings, such as receivers, exporters, processors, connectors, extensions, and service. Requests that set them return a 400 error, and values already stored in a policy are left out of the policy that Fleet sends to agents. If you preconfigure agent policies in kibana.yml, remove these settings from their overrides. To configure collectors, use an OpenTelemetry integration (#305925).
  • Fix agent policies failing to apply when an integration policy ID contains characters that Elasticsearch rejects in role descriptor names, such as IDs generated for Synthetics project monitors (#303384).
Data management
  • Fix the Auto-follow patterns page failing to load, with an "Error loading auto-follow patterns" message, when an auto-follow pattern created through the Elasticsearch API has no follow_index_pattern (#303787).
  • Fix the Create pipeline from CSV file picker showing the file upload size limit, which is 500 MB by default, when Kibana can’t parse CSV files larger than 10 MB. The picker now shows the 10 MB limit, and processing a larger file shows a "File too large" error (#301246).
Discover
  • Fix the "No matching data view" error in the Surrounding documents and Single document views when you use a default data view, such as All logs, and the page reloads, for example after you change the theme (#304432).
Elastic Observability solution
  • Fix APM service dashboards and service metrics dashboards crashing the page with an Embeddable has been destroyed error (#302552).
  • Fix the Synthetics APIs that run a monitor test manually running tests on Elastic managed locations for users who lack permission to use them. The APIs now return a 403 error, like the disabled Run test manually option in the UI (#302483).
  • Fix Synthetics monitor status rule notifications showing the wrong time when you pass context.checkedAt to FormatDate. This happens when the date format has no timezone offset, which is the default, and the Kibana server timezone differs from the dateFormat:tz setting. Use the new context.timestamp action variable, an ISO 8601 time, with FormatDate instead (#302776).
Elastic Security solution
For the Elastic Security 8.19.26 release information, refer to Elastic Security release notes.
Kibana platform
  • Fix the Change password form resetting while you fill it in, which discarded the password you had typed and made the change fail with an Invalid password. error (#301119).
Machine Learning
  • Fix the trained model pipeline simulation having no limit on the number of sample documents or the size of the response. It now accepts at most 100 documents and returns a 413 error when the Elasticsearch response exceeds 10 MB (#304271).
