Logstash 8.19.10 Release Notes

No user-facing changes in Logstash core.

Plugins

Deprecations to Partitioner settings in Kafka output plugin

The partitioner configuration options default and uniform_sticky have been deprecated in the Kafka output. #206

These options will work correctly for the Kafka plugin version bundled with Logstash 8.19.x, but will be removed in a future release.

The deprecations in the Kafka output were made to align with changes in the Kafka Client. At version 4.x, the Kafka Client removes the DefaultPartitioner and UniformStickyPartitioner partitioner implementations. It adds an improved uniform sticky partitioner, which is the default.
