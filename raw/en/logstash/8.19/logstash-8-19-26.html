Logstash 8.19.26 Release Notes

This release contains security fixes. Please see our security advisory for more details.

New features and enhancements

  • Logstash now starts the JVM with -XX:-UseBASE64Intrinsics unless UseBASE64Intrinsics is already set in jvm.options or LS_JAVA_OPTS. To opt back in, set -XX:+UseBASE64Intrinsics #19906

Notable issues fixed

  • Fixed pipelines defined in pipelines.yml no longer being reloaded after a single error while loading their config source. Concurrent config fetches no longer see another pipeline’s settings #19838
  • Fixed Logstash sometimes not exiting after an unexpected fatal error #19729
  • Fixed an issue where frequent requests to the monitoring API (for example from Metricbeat, Elastic Agent, or Kubernetes probes) could increase native memory usage by several hundred MB #19721

Updates to dependencies

  • Windows packages now bundle Temurin 21.0.13+9, matching the other platforms #19808
  • Update the Ironbank Docker image base to UBI 10.3 #19867

Plugins

Rabbitmq Integration - 7.4.5

  • Recover from broker-closed output channels without leaking channels or losing events #88
