Logstash 8.19.19 Release Notes

Deprecation of JDK versions older than 21

Running Logstash on a JDK older than 21 is deprecated. Logstash now logs a warning and a deprecation notice at startup when it runs on Java 11 or Java 17. #19285

These JDK versions continue to work with the Logstash 8.19.x releases, but support for them will be removed in a future release. The bundled JDK is Java 21; to run with a custom JDK, set LS_JAVA_HOME to a Java 21 installation.
