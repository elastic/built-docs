Logstash 8.19.23 Release Notes

Breaking changes

  • Logstash now checks the Java version at startup and refuses to start on a JDK older than 21. JDK 17 was deprecated in 8.19.19, and JDK 21 is the bundled and recommended version. If you set LS_JAVA_HOME to JDK 17 and need to keep using it, add -Dlogstash.jdk17.allow=true to config/jvm.options or LS_JAVA_OPTS; Logstash then logs a warning and starts as usual #19556

Notable issues fixed

  • Fix the resolv gem extension so that Logstash also runs on JDK 17, not only on the bundled JDK 21 #19565

Updates to dependencies

  • Update Jackson to 2.21.7 and jrjackson to 0.5.4 #19588

Plugins

Rabbitmq Integration - 7.4.4

  • Upgrade march_hare to consume 4.10+ #87
